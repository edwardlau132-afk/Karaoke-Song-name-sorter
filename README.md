# Excel Searcher - Karaoke Song Name Sorter

A web-based tool for searching and filtering Excel/CSV files with field-specific search capabilities.

## Features

- 📤 Upload Excel (.xlsx, .xls) or CSV files
- 🔍 Dynamic search fields for each column
- ⚡ Real-time filtering with debounced search
- 📊 Live row count display
- 🎯 Multi-field searching
- ✨ Clean, responsive interface

## How to Use

1. Open the application
2. Click "Upload .xls/.xlsx/.csv" to select your file
3. Search fields will automatically appear for each column
4. Type in any search field to filter results in real-time
5. Click "Clear" to reset all filters

## Supported File Formats

- Excel files (.xlsx, .xls)
- CSV files (.csv)

## Technology Stack

- HTML5
- CSS3
- JavaScript (Vanilla)
- XLSX.js library for Excel parsing

## Installation

1. Clone the repository
2. Open `index.html` in a web browser
3. Start searching!

## Files

- `index.html` - Main HTML structure
- `script.js` - Core search functionality
- `style.css` - Styling and layout
